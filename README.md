# bonitabluehair.com

Can Bonita Bluehair hit level 60 in WoW: Forever before Christmas? This site keeps score.

- **Site:** `index.html` reads `data/history.json` and draws everything in the browser.
- **Updates:** `.github/workflows/update.yml` runs every two hours. It calls `scripts/update.py`, which reads the character from the WoW Forever Armory (through classicarmory.gg), records level snapshots, saves a new character frame to `renders/` whenever the model or gear changes, commits, and redeploys GitHub Pages.
- **Run an update now:** Actions tab → "Update tracker and deploy" → Run workflow.
- **Live XP (optional):** `kit/` holds the XPReport addon (level and XP only) and the XP uploader. The uploader posts `live.json` to the separate `TwinkieSlamer/bonitabluehair-live` repo whenever WoW saves (logout or /reload), and the race page reads it from there. The Armory stays the referee: if a later Armory logout shows a lower level than the addon claimed, the page ignores the addon. Download for players: `downloads/xpreport-kit.zip`.
- **The vote ("Does he make it?"):** the race page reads and saves calls through a small Cloudflare Worker in `votes-worker/`, at https://bonita-votes.votes-worker.workers.dev, backed by a D1 database. Names are optional. The server stamps each call with his level from this site's data, closes voting at 60 or Christmas, and caps new votes at 20 per network per day. Redeploy with `npx wrangler@4.152.0 deploy` from that folder; test locally with `wrangler dev --port 8787` and open the page at `http://localhost:8765/?votes=local`.
- **The 3D stage:** on, with `models/bonita-2026-11-07.glb` (0.4 MB), exported with wow.export 0.2.21 from a local WoW: Forever install: Night Elf female, appearance matched to the Armory render by eye (the Armory doesn't record it), gear from the Armory's item IDs, idle clip only. wow.export leaves the staff and shoulders unattached at the origin; `tools/model/fix-attach.mjs` puts them on their bones and turns the model to face the camera. This is extracted game art, which Blizzard has warned can draw takedowns; to turn it off, set `"model": null` in the manifest. The page only marks the model stale when a newer gear-reel frame lists different gear than the manifest's `gear`. When `models/manifest.json` has a `"model"`, the race page loads `vendor/model-viewer-4.4.0.min.js` (Google, Apache 2.0; meshopt decoder from meshoptimizer 1.2.0, MIT; both checked byte for byte against npm) after the page has loaded, fades the model in over the render, and lets people turn him by drag or arrow keys. It falls back to the render on any failure, offers "Load 3D" on Save-Data or slow connections (or always, with `"autoload": false`), and says "still has his {date} gear" when the gear reel has a newer frame than `exportedAt`. To turn it on:
  1. Export his model as glTF with animations (wow.export, on a PC with WoW: Forever installed; Forever support isn't confirmed). Using a model taken from the game files is the owner's call: Blizzard has warned that datamined assets can draw takedowns.
  2. `cd tools/model && npm install`, then `npx gltf-transform copy bonita.gltf raw.glb`, `node keep-idle.mjs raw.glb idle.glb 1` (clip 1 is Stand), `node fix-attach.mjs idle.glb fixed.glb`, and `npx gltf-transform optimize fixed.glb bonita-YYYY-MM-DD.glb --compress meshopt --texture-compress webp --texture-size 1024 --simplify false --flatten false --join false --instance false --palette false` (aim for under 1 MB).
  3. Put the `.glb` in `models/`, then fill in `manifest.json`: `model`, `bytes`, `exportedAt`, `gearAsOf`, and the framing (`orientation`, `cameraOrbit`, `cameraTarget`, `fieldOfView`) so his feet land on the ground disc and his head in the halo ring. On localhost, `?model=`, `?look=YYYY-MM-DD` and `?sim=savedata|nowebgl` preview the other states.
  4. Export again whenever the gear reel saves a new frame.
- **Change the deadline:** edit `deadline` in `data/history.json` (ISO time, UTC). It's set to midnight Eastern on Dec 25.

Pace math uses the Classic XP table, with play time per level estimated as XP ÷ (45 + 5 × level).
